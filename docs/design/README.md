# Design, v0.2

The requested image concept was generated with the built-in ImageGen tool in generation mode, then implemented as native WPF controls and matching extension HTML/CSS. No screenshot is used as a nonfunctional app background.

- [Generated concept](concept-v0.2.png)
- [Exact generation prompt](prompt.txt)
- UI palette: graphite #101217, raised panels #191D26, borders #2A303C, mint #8CE6BE.
- Three desktop pages: Mixer, Chrome tabs, Settings.
- RU/EN resources update immediately and persist. Each setting has a short label and an information tooltip available by pointer or keyboard focus.
- Source and gain meters display actual engine values.

References reviewed online: [SoundSource](https://rogueamoeba.com/soundsource/) for clear application-level controls and [EarTrumpet](https://github.com/File-New-Project/EarTrumpet) for a focused Windows audio utility. The layout and assets here are original; their logos/assets are not copied.
