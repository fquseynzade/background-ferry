# Background Ferry

**Музыка всегда рядом — и уступает место тому, что ты слушаешь.**

Небольшая программа для Windows 10/11. Автоматически приглушает музыку при появлении звука в выбранных приложениях и плавно возвращает её в паузах. Не требует аккаунта, Spotify API, виртуального аудиодрайвера или прав администратора.

В версии **0.2**: новый тёмный интерфейс, языки RU/EN, подсказки **i** и экспериментальный [микшер вкладок Chrome](docs/chrome-tabs.md). [Макет дизайна](docs/design/README.md).

## Как запустить

1. Распакуй **весь архив** `BackgroundFerry-win-x64.zip` в постоянную папку.
2. Запусти `BackgroundFerry.exe`. .NET уже включён в готовую сборку.
3. Включи музыку и выбери её приложение в **Фоновая музыка**.
4. Запусти видео в другом приложении и отметь его в **Приоритетный звук**.
5. Нажми **Включить микс**.

Например: музыка в Spotify Desktop, видео — в Chrome. Telegram Desktop или локальный плеер тоже могут быть музыкальным источником, если создают управляемую аудиосессию Windows. Совместимость конкретных сервисов отдельно не сертифицирована.

Крестик закрывает окно в трей; микширование продолжается. **Остановить** останавливает обработку и восстанавливает громкость. Для полного выхода: правой кнопкой по значку в трее → **Выйти и вернуть громкость**. В открытом окне работает `Ctrl+M`.

## Что означают настройки

| Настройка | Смысл |
| --- | --- |
| **Steady** | Музыка держится на одном тихом уровне, пока звучит видео. Рекомендуется для речи. |
| **Adaptive** | Музыка немного меняется по уровню видео, оставаясь тихой даже при тихой речи. |
| **Music remaining** | Доля исходной громкости музыки во время приглушения. |
| **Signal threshold** | Порог, начиная с которого звук видео приглушает музыку. Меньше значение — выше чувствительность. |
| **Fade down** | Скорость приглушения. |
| **Wait in silence** | Сколько ждать тишины, прежде чем возвращать музыку. |
| **Fade back** | Скорость возвращения музыки. |

Пример: исходная громкость музыкального приложения в микшере Windows — 50%, Music remaining — 20%. При видео программа установит 10%, а после паузы вернёт 50%. Выше исходного уровня она музыку не поднимает.

При изменении параметров микса он останавливается. Нажми «Включить микс» для применения. Смена языка и настроек запуска микс не останавливает. Наведи мышь на i для подсказки. Если вручную поменять громкость в микшере Windows, программа перестанет управлять этой аудиосессией до следующего запуска микширования.

**Start with Windows** запускает программу в трее, с микшированием **выключенным**. Автозапуск включается только по твоему выбору. Сначала помести программу в постоянную папку.

## Режимы и ограничения

- Язык RU/EN выбирается в правом верхнем углу и сохраняется.
- Микшер Windows работает между приложениями. Для отдельных вкладок используй включённое расширение Chrome: [установка и ограничения](docs/chrome-tabs.md). Оно экспериментальное; реальный захват в этой среде не удалось проверить.
- Работает с обычным совместным режимом аудио Windows; exclusive mode, ASIO и удалённые устройства Spotify Connect не поддерживаются.
- Программа измеряет пики звука, а не распознаёт речь. Уведомление в выбранном приоритетном приложении тоже может сработать.
- После сбоя отдельный процесс пытается восстановить громкость. Это также проверяется при следующем запуске. После отключения устройства, замены аудиосессии или потери питания восстановление не гарантируется.
- Аудио не записывается и никуда не отправляется. Аккаунты музыкальных сервисов подключать не нужно.

Настройки и журнал восстановления: `%LOCALAPPDATA%\BackgroundFerry`. Для удаления отключи автозапуск, выйди через трей и удали папку программы.

## Для разработки и GitHub

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) под Windows.

```powershell
dotnet build BackgroundFerry.slnx -c Release
dotnet run --project src/BackgroundFerry.App -c Release
./scripts/test.ps1
./scripts/publish.ps1
```

Готовый архив появится в `artifacts`. Тесты с реальными аудиосессиями запускаются командой `./scripts/test.ps1 -Integration`: они воспроизводят два очень тихих тестовых тона и меняют громкость только своих процессов.

В репозитории есть CI и автоматический выпуск релиза при отправке тега `v*`. Подробности устройства программы — в [architecture.md](docs/architecture.md). Лицензия — MIT.
